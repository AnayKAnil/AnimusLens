Step-by-Step Tutorials

Detailed guides for all platform features

1

How to Issue a Certificate

  1. Navigate to the "Issue Certificate" page from the main menu
  2. Enter a unique Certificate ID (e.g., "SECURE-2025-001")
  3. Upload your certificate file (PDF, JPG, PNG supported)
  4. Connect your MetaMask wallet when prompted
  5. Review the transaction details and confirm
  6. Wait for blockchain confirmation (usually 30-60 seconds)
  7. Save the transaction hash for future reference
2

How to Verify a Certificate

  1. Go to the "Verify Certificate" page
  2. Enter the Certificate ID you want to verify
  3. Upload the certificate file to check
  4. Click "Verify Certificate" to start the process
  5. System computes SHA-256 hash of uploaded file
  6. Hash is compared with blockchain record
  7. View verification result with timestamp and transaction details
3

MetaMask Setup for Sepolia

  1. Install MetaMask browser extension from metamask.io
  2. Create a new wallet or import existing one
  3. Add Sepolia testnet: Network Name: Sepolia, RPC URL: https://sepolia.infura.io/v3/
  4. Get test ETH from Sepolia faucet for transaction fees
  5. Ensure you're connected to Sepolia network before issuing certificates
  6. Keep your seed phrase secure and never share it

Frequently Asked Questions

Common questions and answers

Blockchain certificate verification stores a unique hash of your certificate on the Ethereum blockchain. This creates an immutable, tamper-proof record that can be used to verify the authenticity of certificates without revealing the actual content.

MetaMask serves as your digital wallet for blockchain interactions, enabling secure transaction signing and payment of gas fees. It's only required when issuing certificates because this process writes data to the Ethereum blockchain, which costs a small transaction fee. Certificate verification is completely free and doesn't need MetaMask - our system reads the existing blockchain public data directly through Web3.py to compare document hashes, making verification accessible to anyone without requiring a crypto wallet or any fees.

Since we use Sepolia testnet, transactions require test ETH which is free to obtain from faucets. In a mainnet deployment, you would pay standard Ethereum gas fees for certificate issuance.

We support PDF, JPG, JPEG, PNG, and most common image formats. The system computes a SHA-256 hash of the file content, so the format doesn't affect verification security.

Certificate verification is instant as it only requires reading from the blockchain. Certificate issuance takes 30-60 seconds depending on network congestion and gas price.

Our smart contract includes revocation functionality. Certificates can be revoked by authorized parties, but the original blockchain record remains immutable for audit purposes.
